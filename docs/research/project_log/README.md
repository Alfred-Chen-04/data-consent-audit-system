# Project Logs

These three files are the long-running internal records that previously lived
in the repository root:

- `task_plan.md`: evolving implementation and research plan.
- `findings.md`: accumulated findings and decisions.
- `progress.md`: chronological execution and verification log.

They are preserved as historical working records, not as the final project
status. References inside older entries may use their former root-level names.
For the completed result, use `../final/FINAL_DELIVERABLES_2026-08-11.md`.
