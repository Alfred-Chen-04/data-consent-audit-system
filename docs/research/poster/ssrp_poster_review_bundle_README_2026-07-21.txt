SSRP Poster Review Bundle, 2026-07-21

Purpose
-------
This bundle packages the existing verified poster-review artifacts into one
file for advisor review. It adds no browser capture, site observation, score,
consent-interface judgment, or confirmed advisor decision.

Recommended review order
------------------------
1. Open ssrp_poster_mockup_2026-07-14.pdf for the print/review poster.
2. Read advisor_email_poster_mockup_review_2026-07-14.md for the five questions.
3. Record actual answers in poster_review_decision_sheet_2026-07-16.csv.
4. Use ssrp_poster_mockup_2026-07-14.pptx only when editable layout review is needed.
5. Use the PNG and QA notes for visual and traceability checks.

Decision state when bundled
---------------------------
- Poster-review sheet: 5 pending rows and 5 blank confirmed decisions.
- Current-five sheet outside this bundle: 7 blank confirmed decisions.
- CMP/manual-review sheet outside this bundle: 8 pending confirmations and
  8 blank confirmed decisions.

Do not copy a recommended default into confirmed_decision without explicit
reviewer confirmation. The pilot/method framing and existing claim guardrails
remain in force until confirmed decisions are recorded.
