# Auxiliary 2025 Data Collection

This is an inherited background collection, not the final SSRP 2026 sample and
not an input to the current automated capture pipeline.

The directory contains 92 site-named folders, 91 Excel workbooks, 231 PNG
screenshots, and the root-level `Record.xlsx`. Site folders generally pair a
`privacy_notice_data.xlsx` workbook with one or more screenshots of an initial
page, banner, preference interaction, or policy page. Filenames record capture
dates in September 2025 where available.

Use this material only as auxiliary historical/reference evidence after
checking its workbook fields, capture context, and provenance. Do not combine
its rows with the controlled five-site pilot or the six-company primary-source
case series without a documented normalization and comparability review.

The project's canonical final evidence is indexed in
`../docs/research/final/FINAL_DELIVERABLES_2026-08-11.md`.
